# 📊 Sales Performance & Business Analytics Dashboard

## 📌 Project Overview

This project analyzes business sales data to understand revenue, profitability, product performance, category performance, regional performance, and sales trends.

The goal is to transform raw sales transaction data into meaningful business insights through data cleaning, exploratory data analysis, and interactive Tableau visualization.

---

## 🎯 Business Objectives

The project focuses on answering key business questions:

- Which products generate the most revenue?
- How do sales change over time?
- Which categories generate the most sales and profit?
- Which regions perform strongly?
- What is the overall profitability of the business?
- Where can the business investigate opportunities for improvement?

---

## 📂 Dataset

**Dataset:** Superstore Sales Dataset

The dataset contains **9,994 sales transaction records** and **21 fields**, including:

- Order Date
- Ship Date
- Customer Information
- Region
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit

The order data covers **2014–2017**.
